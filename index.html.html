Bilangan Bulat terdiri dari bilangan bulat positif, nol, dan bilangan bulat negatif.

Coba bayangkan sebuah Termometer Suhu:

  • Bilangan Positif (+) seperti suhu panas, letaknya di atas nol. Contoh: 5, 10, 25.
  • Nol (0) adalah titik tengah, tidak positif dan tidak negatif. Misalnya saat air membeku.
  • Bilangan Negatif (-) seperti suhu dingin/beku, letaknya di bawah nol. Contoh: -5, -10, -20. Dibaca "negatif lima".

Ingat!

Semakin ke atas/kanan nilainya semakin besar. Semakin ke bawah/kiri nilainya semakin kecil.

-5   <   -2   <   0   <   3   <   7
